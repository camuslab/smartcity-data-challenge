## Development

Astro 6 static site. Start the dev server with `npm run dev` (run it in the background from an agent shell).

- `npm test` — unit tests (Vitest)
- `npm run check` — type check
- `npm run build` — static build into `dist/`

All contest facts (dates, prizes, email, criteria, FAQ) live in `src/data/contest.ts`. Do not hardcode them in components.
